# 🚀 Ishan Singh - Portfolio Website

> A modern, responsive, and interactive personal portfolio website showcasing my software engineering projects, technical skills, professional experience, and achievements as a Java Backend and Full-Stack Developer.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / Modern UI Framework
- **Styling & Icons:** Tailwind CSS / Custom CSS, FontAwesome
- **Deployment & Hosting:** GitHub Pages / Vercel / Netlify

---

## ✨ Features

- **About Me:** Brief introduction highlighting my background, academic pursuit in Computer Science and Engineering at *Galgotias College of Engineering and Technology*, and engineering passion.
- **Projects Showcase:** Detailed cards featuring full-stack and backend systems (such as *DevPilot*, *FindTrain*, *Idempotent Payment Ledger*, and *AI Doctor*), complete with tech stack badges and GitHub repository links.
- **Skills & Expertise:** Categorized breakdown of technical competencies including Java, Spring Boot, Spring Security, Microservices, REST APIs, Databases (MySQL, PostgreSQL), Docker, and Git.
- **Achievements & Metrics:** Highlights of competitive programming milestones (e.g., LeetCode contest rank of 1,470) and professional certifications.
- **Contact Section:** Quick links to connect via Email, LinkedIn, GitHub, and LeetCode.
